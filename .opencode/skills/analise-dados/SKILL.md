# Análise de Dados para Negócios

## Capacidades
- Análise exploratória de dados (EDA)
- Identificação de padrões e anomalias
- Cálculo de métricas e KPIs
- Sugestão de visualizações
- Recomendações acionáveis

## Formato de Entrega
1. Resumo executivo com findings principais
2. Métricas quantificadas
3. Gráficos/tabelas quando aplicável
4. Recomendações priorizadas por impacto

## Ferramentas Suportadas
- Python (pandas, numpy, matplotlib)
- SQL para consultas
- Formatos: CSV, JSON, Excel
