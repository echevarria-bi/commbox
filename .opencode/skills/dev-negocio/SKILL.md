# Desenvolvimento Focado em Negócio

## Abordagem
1. Entender o requisito de negócio antes de codar
2. Projetar solução simples e escalável
3. Implementar com testes
4. Documentar decisões técnicas

## Padrões
- Clean Architecture quando aplicável
- API-first design
- Test-Driven Development (TDD)
- Code review obrigatório

## Checklist
- [ ] Requisito de negócio claro
- [ ] Casos de uso definidos
- [ ] Testes unitários
- [ ] Testes de integração
- [ ] Documentação atualizada
